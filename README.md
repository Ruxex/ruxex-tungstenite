# ruxex-tungstenite

This repository is a Ruxex-maintained downstream fork of [tungstenite](https://github.com/snapview/tungstenite-rs).
It exists solely to publish the Ruxex-compatible package to crates.io and support the Ruxex dependency graph.
Changes are intentionally limited to the proxy compatibility work required by Ruxex.

Thanks to the tungstenite maintainers and contributors, and to OpenAI OSS Forks for the prior work carried here.
